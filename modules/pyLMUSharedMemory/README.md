# pyLMUSharedMemory

Python `ctypes` mapping for reading Le Mans Ultimate's built-in shared-memory
interface.

See the [complete usage guide](USAGE.md) for installation, connection
lifecycle, practical examples, every public method, all enum values, and tables
covering every exported shared-memory field.

The project has no third-party dependencies. It is based on Studio 397's
`SharedMemoryInterface` headers and Tony Whitley's
[pyRfactor2SharedMemory](https://github.com/TonyWhitley/pyRfactor2SharedMemory).
